# 🎮 Rock Paper Scissors — C++

A simple Rock Paper Scissors console game built with C++.

🎯 Features

🎮 Player vs Computer
🎲 Random computer choices
🔢 Choose the number of rounds
📊 Score tracking
🎨 Colored game results
🔄 Play again option
✅ Input validation

🧠 Concepts Used

enum
Functions
if / else
for loops
do while loops
Variables and counters
User input and output
Random number generation
string
Type casting
Basic game logic

🎮 How to Play

Choose the number of rounds.

Choose your option:

🪨 0 → Rock
📄 1 → Paper
✂️ 2 → Scissors

The computer makes a random choice, and the winner is determined according to the classic Rock Paper Scissors rules.

The score is displayed after every round, and you can choose to play again after the game ends.

🏆 Rules

🪨 Rock beats Scissors
📄 Paper beats Rock
✂️ Scissors beats Paper
🤝 Same choice → Draw
